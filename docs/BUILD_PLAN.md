# Tirekick v1 build plan (the contract)

Tirekick is a free, open-source, offline macOS app for checking a used Mac before you pay. It covers Activation Lock,
MDM, company assignment (ABM/ASM), battery, SSD, specs and macOS updates, then guided hardware tests and a shareable
report card. The product decision is `docs/next/PICK.md` §3 in the Whydunit repo (copied facts below). This file is the
build contract for four parallel owners (**core**, **mac**, **app**, **infra**). Where it disagrees with PICK.md, this
file wins; propose changes instead of diverging.

**What has run:** `TirekickCore` (Model, parsers, catalog, rules, report text, keyboard rows; 43 tests) builds and passes on Linux in Docker
(`bash tools/test_core_docker.sh`, 2026-09-28, no warnings). Nothing else has been compiled. There is no Xcode here, so
Mac and App code is "written, not compiled" until a CI run on macOS says otherwise.

## 1. Decisions

| Topic | Decision |
|---|---|
| Platform | macOS **13.0** deployment target, universal (arm64 + x86_64), Swift 5 language mode (`swiftLanguageModes: [.v5]`, `SWIFT_VERSION = 5.0`), built with Xcode 26. Not sandboxed. Hardened runtime. Developer ID signed and notarized from the first public release. |
| State | `ObservableObject` + `@Published` + `@StateObject`/`@EnvironmentObject`. Never `@Observable`/`@Bindable` (macOS 14). |
| Packages | One SwiftPM package at the repo root (`Package.swift`, frozen): `TirekickCore` (Foundation-only, builds on Linux) and `TirekickMac` (macOS only). App target in `App/`, generated by XcodeGen (`project.yml`). **No third-party dependencies.** No Sparkle. |
| Model data | `ModelCatalog` is embedded Swift data (no SwiftPM resources, no models.json file), so it builds and tests on Linux. |
| Network | None. No telemetry, no update check, no URLSession. Links open in the user's browser only on a click. |
| Writes | None, except a report the user saves through `NSSavePanel` (PNG or PDF). No `UserDefaults`/`@AppStorage`: v1 has zero settings. |
| Processes | `Process` only through `ProcessRunner` (copied verbatim from Whydunit), only for `Command.all` (§3). |
| Window | One fixed ~720×560 window, four screens like Setup Assistant: Welcome → Checks → Tests → Report. No sidebar, no menu bar extra, no login item, nothing in the background. |
| Localization | English only in v1. zh-Hans is a Should (String Catalog later): keep user-facing strings in `Text("…")` literals and Core copy in one place per file so extraction is easy. |
| Bundle ID | `io.github.everydayopen.tirekick` (infra may change it before the first signed build). |

## 2. What the commands print (researched 2026-09-28)

Real samples are in `Tests/TirekickCoreTests/Fixtures/` with their source URLs in its README. **VERIFY** = no verbatim
sample yet; the CI dump job (§2.4) and beta testers' "Copy raw data" close these.

### 2.1 `system_profiler -json <DataType>`

All are `{ "<DataType>": [ … ] }`. Values are strings unless noted. Parsers must tolerate missing keys and extra keys.

**SPHardwareDataType**: one item, `_name: "hardware_overview"`.

| Key | Values seen | Notes |
|---|---|---|
| `activation_lock_status` | `"activation_lock_enabled"`, `"activation_lock_disabled"` | Absent → `.notReported` (VERIFY: Intel without T2). Any other value → nil (unread). |
| `machine_model` | `"Mac17,6"`, `"MacBookAir10,1"`, `"iMacPro1,1"` | The identifier for ModelCatalog. |
| `machine_name` | `"MacBook Pro"`, `"MacBook Air"`, `"iMac Pro"` | |
| `chip_type` | `"Apple M1"`, `"Apple M5 Max"` | Apple silicon only. The MacBook Neo has an A18 Pro, so test the `"Apple "` prefix, not `"Apple M"`. |
| `cpu_type`, `current_processor_speed` | `"8-Core Intel Xeon W"`, `"3.2 GHz"` | Intel. `cpu_type: "Unknown"` when read from an x86_64 process on Apple silicon (Rosetta). Prefer sysctl `machdep.cpu.brand_string` for the chip on Intel. |
| `number_processors` | **String** `"proc 8:4:4"`, `"proc 18:6:0:12"` (Apple silicon); **Int** `8` (Intel) | The JSON type differs. Take the total only (first number); get core groups from sysctl. |
| `physical_memory` | `"16 GB"`, `"128 GB"` | Fallback for `hw.memsize`. |
| `serial_number`, `platform_UUID`, `provisioning_UDID` | | Redact (§4.5). |

**SPPowerDataType**: several items; the battery is the item containing `sppower_battery_health_info` (don't rely on
`_name == "spbattery_information"`, published excerpts omit it). Desktops have no such item.

| Key (inside `sppower_battery_health_info`) | Values seen | Notes |
|---|---|---|
| `sppower_battery_cycle_count` | Int `38`, `88`, `745` | |
| `sppower_battery_health` | `"Good"`, `"Check Battery"` | JSON values differ from the text report ("Normal", "Service Recommended"). Anything but `"Good"` → Check. Other strings VERIFY. |
| `sppower_battery_health_maximum_capacity` | `"83%"`, `"88%"` | Apple silicon. Absent on Intel in published samples: compute from ioreg. |

**SPStorageDataType**: one item per mounted volume. Use the item with `mount_point == "/"` (else the first with
`physical_drive.is_internal_disk == "yes"`). Its `physical_drive` has `device_name` (`"APPLE SSD AP1024Z"`),
`is_internal_disk` (`"yes"`/`"no"`), `medium_type` (`"ssd"`), `protocol` (`"Apple Fabric"`, `"USB"`), `smart_status`
(`"Verified"`; `"Failing"` and `"Not Supported"` VERIFY). External drives have no `smart_status`. The item's
`size_in_bytes` (Int, `994662584320` on a 1 TB drive) is the APFS container, a little below the drive's size.

**SPNVMeDataType** (VERIFY, no verbatim sample): `[{ "_name": <controller>, "_items": [{ "_name", "bsd_name",
"device_model", "device_serial", "size", "size_in_bytes" (Int), "smart_status", "spnvme_trim_support",
"detachable_drive", "removable_media", "volumes": [...] }] }]` per gopsutil's parser. Use `size_in_bytes` of the
non-detachable item as the exact drive size. Intel Macs with SATA/AHCI SSDs have no NVMe entry: fall back to
SPStorageDataType (`capacityIsApproximate = true`).

**SPDisplaysDataType**: one item per GPU: `"sppci_cores": "14"` (**String**, Apple silicon only), `sppci_model`,
`spdisplays_ndrvs` (displays; built-in has `spdisplays_connection_type: "spdisplays_internal"`,
`_spdisplays_pixels: "3024 x 1964"`). v1 reads only GPU cores.

### 2.2 Other commands

**`/usr/sbin/sysctl hw.model hw.memsize hw.nperflevels hw.perflevel0.name hw.perflevel0.physicalcpu hw.perflevel1.name hw.perflevel1.physicalcpu machdep.cpu.brand_string`**:
`name: value` lines (`hw.memsize: 17179869184`, `hw.perflevel0.name: Super`, `hw.perflevel0.physicalcpu: 6`,
`hw.perflevel1.name: Performance`). Core groups come from the perflevel names, so M5's "Super" cores need no code change.
Intel has no perflevel keys: sysctl prints an error to stderr for each unknown name (VERIFY: it keeps going and exits
non-zero). Parse stdout whatever the exit status.

**`/usr/sbin/ioreg -r -c AppleSmartBattery -a`**: a plist `<array>` with one `<dict>` (empty array on desktops).
Keys Tirekick reads: `DesignCapacity` (mAh), `AppleRawMaxCapacity` (mAh), `NominalChargeCapacity` (mAh), `CycleCount`,
`DesignCycleCount9C` (1000 on an M1 Max), `PermanentFailureStatus` (0; non-zero like 4096 reported on dead batteries).
**`MaxCapacity` is 100 on Apple silicon** (the charge-percent denominator, not health) and mAh on Intel; never use it
for health on Apple silicon. Health precedence (as Mole settled): system_profiler's maximum capacity, else
`AppleRawMaxCapacity / DesignCapacity`, else `NominalChargeCapacity / DesignCapacity`. `PropertyListSerialization` parses
XML plists on Linux too.

**`/usr/bin/profiles status -type enrollment`** (runs without root: Der Flounder's 2018 samples use a normal prompt,
and Chromium runs it as the logged-in user in `base/enterprise_util_mac.mm`; VERIFY on macOS 13–27 with `sudo -u nobody`):

```text
Enrolled via DEP: No|Yes
MDM enrollment: No|Yes|Yes (User Approved)
MDM server: https://…          (only when enrolled; the value contains ':' so split on the first ': ')
```

Ignore other lines. Unknown values for the two known keys → nil (unknown), never "No".

**`sudo /usr/bin/profiles show -type enrollment`** (the user runs it; needs admin and internet):

```text
Device Enrollment configuration:
{
    ConfigurationURL = "https://…";
    IsMDMUnremovable = 0;
    OrganizationName = "Twocanoes Software";
    OrganizationCity = Naperville;          ← unquoted when the value is one word
    …
}
```

- `Device Enrollment configuration:` followed by a `{` line → `.assigned(organization:, mdmUnremovable:)` with
  `OrganizationName = …;` as the organization (strip quotes; `IsMDMUnremovable = 1` → true). A block without
  OrganizationName → `.assigned(organization: nil, …)`. The header without a `{` block (the two-line `(null)` output) is
  not assigned-or-not: `.couldNotCheck`.
- `Error fetching Device Enrollment configuration: Client is not DEP enabled.` → `.notAssigned`.
- `Error fetching Device Enrollment configuration: (34006) … The cloud configuration server is unavailable. …` or any
  other text (including `(null)`, a sudo password error, or text that isn't profiles output) → `.couldNotCheck(reason)`
  with the first `(null)` or known error line (`Error fetching …`, `sudo:`, `profiles:`, `Sorry, try again`) as the reason,
  else `Parsers.unrecognizedPaste` (never echo other lines: they may be a password). Pasted Terminal prompts (`jane@Janes-MacBook ~ %`, `Host:dir user$`)
  are reduced to `% ` first (`Redact.prompts`), so the reason never names the user or the Mac. Never treat
  unrecognized text as "not assigned".
- VERIFY: the strings on macOS 13–27, and whether running it shows an enrollment notification.

**`/usr/bin/fdesetup status`**: `FileVault is On.` / `FileVault is Off.` (works as a standard user; extra lines while
encrypting are VERIFY). Anything else → nil.

**`~/Library/Preferences/MobileMeAccounts.plist`** (read by the Mac layer, not a process): the `Accounts` array's count
is the only thing that leaves the Mac layer, as `rawOutput: "Accounts: N"`. Missing file → `"Accounts: 0"`; a readable
plist without an `Accounts` array → `rawOutput: ""` + an errorOutput, so `iCloudSignedIn` is nil (couldn't tell). VERIFY the
file still exists on 13–27.

## 3. Safety rules (review + CI; all hard)

1. **Read-only.** Never delete, trash, move, rename or write anything, except a report the user saves through
   `NSSavePanel`. No settings are changed, nobody is signed out, nothing is erased. Deep links only.
2. **No shell.** `Process` only inside `ProcessRunner`, which is internal to `TirekickMac`; `ProcessRunner.run` only
   inside `Collector`; the command must be in `Command.all` (a `precondition` in `Collector.run`). No `NSTask`,
   `Process.run`, `system`, `popen`, `posix_spawn` or `exec*`. `Command` values are defined only in
   `Sources/TirekickCore/Model/Evidence.swift`. Allowlist: `/usr/sbin/system_profiler`, `/usr/bin/profiles` (first
   argument `status` only), `/usr/sbin/ioreg`, `/usr/sbin/sysctl`, `/usr/bin/fdesetup` (first argument `status` only).
   The app contains no privileged code; admin rights are typed into Terminal, never into Tirekick.
3. **No network.** No URLSession, Network framework, web views, sockets, `AsyncImage` or `Data`/`String(contentsOf:)`.
4. **Never help bypass MDM or Activation Lock.** No copy, link or code that removes, hides or works around either. The
   only advice is "ask the seller" or "only that organization can release it".
5. **Findings, not guarantees.** Every check shows the command and raw output. "Walk away" only for: Activation Lock
   on, DEP or MDM enrolled, an ABM organization found, SMART failing. Never "certified", "guaranteed" or "safe to buy".
6. **Redaction by default** on the share card and in "Copy raw data": serial masked to the last 4 characters; no user
   name, host name or Apple Account. The report has a "What Tirekick can't tell you" section.
7. **Camera and microphone** permission prompts appear only when the user starts those tests. Nothing is recorded or saved.
8. **Never name the AI tooling** used to build this repo in any file, comment, doc or commit message.

### 4.2 Parsing (`Parse/`)

```swift
public enum Parsers {
    /// SPHardwareDataType JSON (+ sysctl stdout, + SPDisplaysDataType JSON for GPU cores). nil if the hardware JSON is unreadable.
    public static func specs(hardwareJSON: String, sysctl: String?, displaysJSON: String?) -> MacSpecs?
    /// nil when neither source has a battery.
    public static func battery(powerJSON: String?, ioregPlist: String?) -> BatteryInfo?
    public static func storage(storageJSON: String?, nvmeJSON: String?) -> StorageInfo?

    /// "Accounts: N" → N > 0.
    public static func iCloudSignedIn(_ summary: String) -> Bool?
    /// "name: value" lines → dictionary (split on the first ": ").
    public static func sysctl(_ output: String) -> [String: String]
}

extension Facts {
    /// Runs every parser on its Evidence.rawOutput (nil evidence → nil field) and ModelCatalog.lookup.
    public init(_ raw: RawData)
}
```

### 4.4 VerdictRules (`Rules/VerdictRules.swift`)

```swift
public enum VerdictRules {
```

| CheckID | Evidence | Verdict rule | Title (examples) |
|---|---|---|---|
| activationLock | hardware | `.enabled` → **walkAway**; `.disabled` → clean; `.notReported` → **check** ("Couldn't check") when `isAppleSilicon`, else unknown (pre-T2 Intel); nil (no specs or an unrecognized value) → **check** | "Activation Lock is on" · "Activation Lock is off" · "This Mac doesn't report Activation Lock" |
| mdmEnrollment | enrollment | DEP Yes or MDM Yes → **walkAway**; both No → clean; else **check** | "Set up by an organization (Automated Device Enrollment)" · "Managed by an organization (MDM)" · "Not managed by any organization" |
| companyAssignment | abmPaste | `.assigned` (header followed by `{`) → **walkAway**; `.notAssigned` → clean; `.couldNotCheck`/`.notChecked` → **check**. Evidence is `Parsers.abmExcerpt`: from the last `profiles show` line, only the lines `abm` reads (command, `Password:`, `(null)`, known errors, sudoers refusals, the header and its `{…}` block) | "Assigned to “Acme Corp” in Apple Business" · "Not assigned to any company" · "Company check not run yet" |
| specs | hardware, sysctl, storage | buying only. `listingMatches` true → clean, false → check, nil (not answered yet) → **check** | "Matches the listing" · "Doesn't match the listing" · "Compare with the listing" |
| battery | power, battery | Omitted when `specs.isLaptop == false` and no battery. Condition ≠ "Good", capacity < 80% or permanent failure → check; else clean; no data on a laptop → unknown | "Battery at 81%, 540 of 1,000 rated cycles" · "Battery needs service (macOS says: Check Battery)" |
| storageHealth | storage, nvme | "Verified" → clean; "Failing" → **walkAway**; else unknown | "SSD reports healthy (SMART: Verified)" · "SSD reports it's failing" · "The SSD doesn't report its health" |
| macOSUpdates | a synthesized Evidence: command "Tirekick model list (built in)", rawOutput "Mac15,6 → MacBook Pro (14-inch, Nov 2023), last macOS: current" | model unknown → unknown, except an older family name (`MacBookPro`, `MacBookAir`, `MacBook`, `iMacPro`, `iMac`, `Macmini`, `MacPro`) not in the list → check "Apple doesn't support macOS N on this Mac"; `lastMacOS == nil` → clean; otherwise check, by release distance: 1 → "about 2 more years of security updates (not guaranteed)", 2 → "about 1 more year", ≥3 → no longer patched | "Gets macOS 27, the current version" · "macOS 26 is its last" · "Newer than this version of Tirekick" |
| iCloudSignedOut | iCloudAccounts | selling only. signed in → check; out → clean; nil → unknown | "Still signed in to iCloud" · "Signed out of iCloud" |
| fileVault | fileVault | selling only. off → check; on → clean; nil → unknown | "FileVault is off" · "FileVault is on" |

"Couldn't check" is unknown, except for the hard facts (Activation Lock unread or not reported on Apple silicon, device
management, the company check): an unread hard fact is **check**, so it can't pass as a gap. Verdicts are facts and don't change with
the mode; only `detail` wording does (buyer: "Don't pay while it's on. Ask
the seller to turn off Find My in front of you, then choose Check Again."; seller: "Turn off Find My, then choose Check
Again."). Details are at most 3 sentences and follow §8.

### 4.5 Report text and redaction (`Report/`)

```swift
public enum Redact {
    /// "····G5J7" (last 4); nil → "Unknown".
    public static func serial(_ serial: String?) -> String
    /// Masks the serial wherever it appears plus the values of serial_number, platform_UUID, provisioning_UDID,
    /// device_serial and ioreg "Serial" (JSON, ioreg text and plist forms), and turns pasted Terminal prompts into "% ".
    public static func evidence(_ text: String, serial: String?) -> String
}

public enum Format {
    public static func storage(_ bytes: Int64?) -> String   // nearest marketing size: "512 GB", "1 TB"; nil → "Unknown"
    public static func memory(_ bytes: Int64?) -> String    // binary GB as Apple labels RAM: 17179869184 → "16 GB"
    public static func date(_ date: Date) -> String         // "12 Nov 2026" (en_US_POSIX "d MMM yyyy" in v1)
}

public enum ReportText {
    /// Model, Identifier, Chip, CPU ("11 cores: 5 Performance + 6 Efficiency"), GPU, Memory, Storage, Serial, macOS.
    public static func specRows(_ facts: Facts, maskSerial: Bool) -> [SpecRow]
    /// "Checked 9 things · 2 to check · 1 couldn't check" (zero parts left out).
    public static func summaryLine(_ checks: [Check]) -> String
    public static func card(_ report: Report, maskSerial: Bool) -> ReportCard
    /// Plain text for the PDF and Copy: header, verdict, specs, each check with its evidence (always redacted), tests
    /// (skipped ones as "[Skipped] Camera"), "What Tirekick can't tell you", footer. "Mask serial" only
    /// changes the Serial row and the footer.
    public static func full(_ report: Report, maskSerial: Bool) -> String
    /// Every Evidence in RawData, always redacted: testers send this as a fixture.
    public static func rawData(_ raw: RawData) -> String
    /// Stolen or blacklisted status, Intel firmware password, parts and repair history, liquid damage.
    public static let cantTell: [String]
}
```

Card: title "Tirekick report · {model name} · {chip} {N}-core · {memory} · {storage}". The card leaves out the listing
question (`.specs`), the seller's `.iCloudSignedOut` and `.fileVault`, and skipped tests; its verdict and `headline`
(`bannerTitle(for: mode)`) come from what's left. `summary` = the worst check's title and detail when it's check or
worse, else the first test with a problem, else the first unknown check's title and detail (nil when all clean). One
row per remaining check and one per finished, not skipped, test ("Keyboard: 78 of 78 keys"); footer "Checked {date} on this Mac · Serial
{masked} · Only trust a check you run yourself: Tirekick (free)".

### 4.6 Keyboard (`Keyboard/`)

