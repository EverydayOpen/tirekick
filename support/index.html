Support

Report a problem or ask a question on GitHub Issues. Please include the Mac's model, its macOS version and, if you can, the raw output (see below).

Sending the raw output

When a check says “Couldn't check” or looks wrong, the fastest fix starts with exactly what your Mac printed.

  1. Open Tirekick and run the checks.
  2. Choose Help › Copy Raw Data. It copies every command Tirekick ran and its output, with the serial number and hardware identifiers masked.
  3. Paste it into your issue.

Issues on GitHub are public, so read it before you post it and remove anything you'd rather not share. Each report from a real Mac becomes a test that keeps that Mac's output working in future versions.

The company check says “Couldn't check”

The command you run in Terminal asks Apple's servers, so the Mac needs the internet, and your password must be an administrator's. Connect to Wi-Fi, run sudo /usr/bin/profiles show -type enrollment again and paste the whole output. An error that mentions the cloud configuration server usually means no internet connection. Tirekick never treats an error as “not assigned”.

What Tirekick can't tell you

  • Whether the Mac was reported lost or stolen. No public lookup exists.
  • Whether an Intel Mac has a firmware password.
  • Parts and repair history, and liquid damage.
  • Whether the seller owns the Mac. Ask for the receipt.

It also can't run on a Mac stuck at the setup screen, or on Macs too old for macOS 13. The meetup checklist covers both.

Can it remove MDM or Activation Lock?

No, and it never will. Only the owner can turn off Activation Lock, and only the organization can release a Mac it owns. See how to check a used Mac for MDM.
