02 · The listing says

The listing says it's fine. Check anyway.

The expensive surprises don't show in photos, and most of them don't show until after you've paid.

04 · Hands-on tests

Then test what you'll touch. Every day.

Six guided tests, each ending in Pass, Problem or Skip.

Keyboard

Press every key and watch it light up on an ANSI or ISO layout. Keys macOS keeps for itself get a tick-it-yourself fallback.

Display

Full-screen white, black, red, green, blue, gray and a checkerboard, for dead pixels, tint and backlight bleed.

Speakers

A tone in the left speaker, the right, then both, so a dead channel can't hide.

Microphone

A live level meter. Talk and watch it move. Nothing is recorded.

Camera

A live preview, on only while the test is open. Nothing is recorded or saved.

Trackpad

Click, Force Click and two-finger scroll, each ticked off as it works.

06 · Honest limits

What it can tell you. And what it can't.

Tirekick reports what macOS reports. Some things no app on the Mac can see.

  • How worn it is

    Battery capacity and cycles, and the SSD's SMART status.

  • How long it gets updates

  • Ownership

It will never help bypass MDM or Activation Lock

Tirekick doesn't remove, hide or work around either, and never will. A “bypass” doesn't take the Mac out of the organization's account, so the lock can come back after an update or an erase. Only the owner can turn off Activation Lock, and only the organization can release a Mac it owns.

Runs offline. Sends nothing. Reads nothing personal. Changes nothing.

  • Runs offline

    It works without a network connection: no update check, no analytics, no crash reporting.

  • Sends nothing

    Nothing leaves the Mac unless you save or copy a report and share it yourself.

  • Reads nothing personal

    Hardware and system status, not files, mail or photos. For the seller checklist it counts iCloud accounts, never reading which one.

  • Changes nothing

    It never deletes, moves or changes anything, and never signs anyone out. It runs no shell, only the Apple tools in the table above.

08 · Questions

Questions. Straight answers.

Something else? Ask on GitHub.

Is it really free?

Yes. Every feature, on every Mac, with no account, ads or in-app purchases. The source code is on GitHub under the MIT License.

The Mac was erased and is at the setup screen. Can I still use it?

Go through setup connected to Wi-Fi or a phone hotspot, finish with a throwaway local account and no Apple Account, then open Tirekick from a USB stick. If setup asks for someone else's Apple Account, it's Activation-Locked. A Remote Management screen means an organization owns it. Walk away from either.

Why does the company check need Terminal?

Asking Apple whether a Mac is assigned to an organization needs administrator rights and the internet. Tirekick has neither by design: it never asks for your password and never goes online. So it shows you one command to run in Terminal, and reads the result you paste back.

Which Macs does it run on?

Any Mac with macOS {{minMacOS}} or later, Apple silicon or Intel. Older Macs that stop at macOS 12 can't run it, but the meetup checklist lists the same checks by hand.

Can a seller fake the report?

Anyone can edit a picture. That's why every card says “Only trust a check you run yourself.” Tirekick is free, so run it on the Mac in front of you.

Why isn't it on the Mac App Store?

It runs Apple's own tools, like system_profiler and profiles, which the App Store's sandbox doesn't allow. It's signed with an Apple Developer ID and notarized by Apple.

Something looks wrong. Where do I get help?

Open an issue on GitHub. The support page shows how to include the raw output, with the serial masked, so we can see what your Mac reported.
