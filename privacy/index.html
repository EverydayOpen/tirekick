Privacy Policy

Last updated 28 September 2026

The short version

  • Runs offline. The app makes no network connections at all: no analytics, no crash reporting, no update check.
  • Sends nothing. Nothing leaves the Mac unless you save or copy a report and share it yourself.
  • Reads nothing personal. It reads hardware and system status, not your files, mail, photos or Apple Account.
  • Changes nothing. It never deletes, moves or changes anything. Tirekick itself stores no settings or logs and writes no files except a report you save; like any Mac app, macOS may remember its window position and last save folder.

We collect no personal data, in the app or on this website.

Who we are

Tirekick is made by EverydayOpen (“we”, “us”). Its source code is public on GitHub, so you can check everything on this page. For anything about privacy, open an issue on GitHub Issues.

What the app reads on the Mac

  • Hardware and system status, by running Apple's own tools with fixed arguments: system_profiler (hardware, power, storage and display information), ioreg (battery), sysctl (model, memory and processor), profiles status (device management enrollment) and fdesetup status (whether FileVault is on). The results include the Mac's serial number and hardware identifiers. They stay in the app's memory and are gone when you quit.
  • iCloud sign-in: the number of accounts in ~/Library/Preferences/MobileMeAccounts.plist. The app keeps only that number, never the account's name or email address.
  • The company check: if you choose to, you run a command in Terminal and paste its output into the app. That command, not Tirekick, contacts Apple. The pasted text stays in the app's memory.
  • Camera and microphone: only while you have the camera or microphone test open, and only after macOS asks for your permission. The picture and the sound level are shown live and never recorded or saved. You can change the permission any time in System Settings › Privacy & Security.
  • Keyboard and trackpad tests: key presses and clicks inside Tirekick's own window, only to tick them off. They're never recorded.

What the app writes

Tirekick itself writes nothing unless you save a report. Like any Mac app, macOS may remember its window position and the folder you last saved to. Save PNG and Save PDF write a file where you choose. Copy puts the report on the clipboard. Reports mask the serial number to its last 4 characters by default, and never include your user name, computer name or Apple Account. If you turn off Mask serial, the full serial number is in the report; think twice before posting it publicly.

What the app sends over the internet

Nothing. Tirekick makes no network connections, and an automated check on every code change rejects the common ways code could. Links, such as the Help menu's link to this website, open in your browser.

This website

This site and the app's downloads are hosted by GitHub (GitHub Pages and GitHub Releases). GitHub logs the IP address of every visitor for security purposes, under its own privacy statement. We don't get those logs. The site sets no cookies and loads no analytics, fonts or scripts from other servers.

GitHub Issues

If you open an issue or comment on GitHub, what you write is public, and GitHub stores it under its privacy statement. We use it only to help you. If you paste the app's raw output, the serial number is already masked, but read it before you post it. You can edit or delete your own comments at any time, and we will delete an issue you opened if you ask.

Your rights

We don't receive or keep any personal data from the app. The only personal data we handle is what you choose to post on GitHub Issues, which we use to answer you (our legitimate interest). To have it removed, ask in the issue or delete it yourself. If you are unhappy with how we handle your data, you can complain to your local data protection authority.

We are based in India. GitHub may process data in the United States and elsewhere. For transfers from the UK and EEA, GitHub relies on Standard Contractual Clauses and the EU-U.S. Data Privacy Framework (see its privacy statement).

Children

Tirekick is not directed at children and we don't knowingly collect data from them.

Changes

If this policy changes, we update the date at the top.
